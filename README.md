- x402 manifests: `/.well-known/x402`
- MCP manifests: `/.well-known/mcp.json`
- AI plugin manifests: `/.well-known/ai-plugin.json`
- Data catalog: https://open-books.alfrexo95.workers.dev/data/catalog

